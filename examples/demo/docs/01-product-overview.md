# NexusFlow 产品概览

NexusFlow 是一个企业级知识检索与智能体编排平台。它把文档解析、混合检索、RAG 问答、工作流编排、工具调用与人工审批放在同一个控制台和同一套 API 之下。

## 核心组件

- **Go Gateway**：统一入口，负责登录鉴权、RBAC、租户隔离、限流、API Key、Webhook 与各服务代理。
- **Python Agent Hub**：RAG 问答、意图识别、摘要与记忆抽取；可选开启工具调用、推理循环、MCP 服务端与人工审批。
- **Workflow Engine（Go）**：执行 DAG 工作流，支持条件分支、并行循环、Agent 节点、人工审批挂起与恢复。
- **LlamaIndex 检索服务**：负责切块、向量化、稀疏索引、Qdrant 检索、RRF 融合与重排序；可选启用 LightRAG 图谱增强。
- **MinerU 解析**：把 PDF 等版式文档解析为 Markdown、图片与布局 JSON（layout.json）。
- **基础设施**：PostgreSQL（身份、审批、审计、快照）、Redis（会话与令牌吊销）、RabbitMQ（任务队列）、Qdrant（向量与稀疏检索）。

## 典型使用路径

1. 在控制台创建知识库并上传文档。
2. 等待解析与索引完成，在“检索测试”页验证召回效果。
3. 在“智能问答”页提问，检查回答中的引用来源。
4. 需要多步骤处理时，在“工作流编排”页组合节点并试运行。
5. 高风险动作（例如工具执行）通过“审批中心”人工确认后继续。
6. 对外集成时签发 API Key，或订阅 Webhook 事件。

## 权限模型

平台同时存在两套角色：

- **平台角色**：`admin`、`editor`、`viewer`，决定能否管理用户、上传文件、执行沙箱或运行工作流。
- **知识库角色**：`kb:admin`、`kb:editor`、`kb:viewer`，按知识库单独授权，控制单个知识库的读写。

租户（tenant）之间默认完全隔离：任务、文件、检索、会话、Webhook 与 API Key 都按租户隔离。
